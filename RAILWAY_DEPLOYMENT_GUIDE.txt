============================================================
TROUBLESHOOTING
============================================================

PROBLEM: "CORS error" in browser console
FIX: Double-check CORS_ALLOWED_ORIGINS variable in Laravel service.
     Make sure it matches your React domain EXACTLY (with https://).

PROBLEM: "401 Unauthorized" on API calls
FIX: Check SANCTUM_STATEFUL_DOMAINS variable.
     Must be domain only (no https://, no trailing slash).

PROBLEM: "500 Server Error"
FIX: Check Laravel build logs in Railway.
     Common issue: APP_KEY not set. Regenerate with:
     php artisan key:generate --show

PROBLEM: Database tables don't exist
FIX: The start command includes "php artisan migrate --force"
     which runs automatically. Check build logs for migration errors.

PROBLEM: Empty database (no admin user)
FIX: Run the seeder (see Step 9, item 3).

PROBLEM: Build fails with "composer not found"
FIX: The nixpacks.toml handles this. Make sure the file exists
     in laravel-backend/nixpacks.toml
